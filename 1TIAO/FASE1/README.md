## 🎯 Objetivo da Fase

O foco principal desta fase foi construir uma base analítica e computacional sólida, aplicando algoritmos de tomada de decisão, estatística descritiva e visão computacional para resolver problemas reais de mercado e impacto social.

- Desenvolver aplicações estruturadas e interativas em Python com lógica de vetores, repetição e decisões
- Realizar análises estatísticas e integrações com APIs meteorológicas em R
- Criar e avaliar modelos práticos de classificação de imagens utilizando Visão Computacional
- Analisar o impacto social da tecnologia agrícola por meio de revisões acadêmicas
- Trabalhar de forma colaborativa utilizando versionamento de código com Git/GitHub

---

## 📖 Conteúdos Abordados

- **Lógica e Estrutura de Dados:** Manipulação de vetores, laços de repetição, estruturas condicionais e modularização de código em Python.
- **Estatística Aplicada & Integração de APIs:** Cálculo de estatística descritiva (média e desvio padrão), consumo de APIs REST/JSON (Nominatim e Open-Meteo) em R.
- **Visão Computacional e IA:** Treinamento, validação e ajuste de hiperparâmetros (épocas, batch size, learning rate) para classificação de imagens via Teachable Machine.
- **Inovação Agrícola e Impacto Social:** Estudo do uso de Veículos Aéreos Não Tripulados (VANTs) na Agricultura de Precisão.

---

## 🛠 Tecnologias Utilizadas

Durante esta fase, foram utilizadas as seguintes tecnologias:

- **Python 3:** Construção da CLI e lógica de gerenciamento agrícola
- **R:** Processamento de dados estatísticos e integração meteorológica via API
- **Teachable Machine (Google):** Treinamento de modelos de visão computacional
- **Git & GitHub:** Versionamento e gestão colaborativa de código
- **Open-Meteo & Nominatim APIs:** Requisições de geocodificação e dados climáticos
- **Unittest:** Testes unitários automatizados em Python

## 📂 Projetos Desenvolvidos

### 📌 Projeto 1 — FarmTech Solutions (Gestão Agrícola & Análise Climática)

**Descrição:**  
Desenvolvimento de uma solução multiplataforma (Python e R) para a startup *FarmTech Solutions*, simulando a migração de uma propriedade rural para a Agricultura Digital. O sistema Python gerencia culturas, áreas geométricamente calculadas e manejo de insumos. A aplicação em R realiza o processamento estatístico dessas métricas e consulta previsões do tempo em tempo real via API pública.

**Tecnologias utilizadas:**  
- Python
- R
- APIs Open-Meteo / Nominatim
- Unittest

**Principais aprendizados:**  
- Estruturação de menus CLI interativos e modularização de software (`main`, `calculations`, `data_handler`).
- Manipulação de dados estruturados em vetores e tratamento estatístico.
- Consumo e tratamento de dados de APIs externas via R.

---

### 📌 Projeto 2 — Detecção e Classificação de Utensílios de Cozinha com IA

**Descrição:**  
Desenvolvimento e avaliação de um modelo de Visão Computacional treinado via Google Teachable Machine para identificar e categorizar utensílios domésticos (panelas, pratos e talheres). A solução visa promover acessibilidade para pessoas com deficiência visual e otimização de espaços.

**Tecnologias utilizadas:**  
- Google Teachable Machine
- Ferramentas de Visão Computacional / Image Classification

**Principais aprendizados:**  
- Curadoria e preparação de datasets de imagem (treinamento e teste).
- Ajuste e impacto de hiperparâmetros (épocas, tamanho do lote e taxa de aprendizado) na acurácia do modelo.
- Análise crítica de matrizes de confusão e métricas de desempenho em modelos de IA.

---

### 📌 Projeto 3 — Estudo de Impacto Social: VANTs na Agricultura de Precisão

**Descrição:**  
Elaboração de síntese crítica e análise do artigo científico da Embrapa sobre a aplicação de drones/VANTs no monitoramento agrícola, avaliando sensores espectrais, geoprocessamento e os desafios regulatórios/operacionais no Brasil.

**Tecnologias utilizadas:**  
- Análise crítica acadêmica
- Pesquisa bibliográfica em Inteligência Agrícola

**Principais aprendizados:**  
- Compreensão das tecnologias de sensoriamento remoto (câmeras RGB, multiespectrais e térmicas).
- Visão de mercado sobre regulamentações operacionais e viabilidade econômica em tecnologias emergentes.
